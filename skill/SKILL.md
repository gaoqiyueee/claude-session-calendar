# 会话目标与自评

脚本：`python3 ~/.claude/skills/session-goal/scripts/sg.py`（下文写作 `sg`）。会话 ID 自动取 `$CLAUDE_CODE_SESSION_ID`；加 `--project` 就改成操作当前会话所在的项目（项目 = 会话启动目录）。

| 用户意图 | 命令 |
|---|---|
| 看当前目标和进度 | `sg show` |
| 设会话目标 | `sg goal "一句话目标"` |
| 设项目目标 | `sg goal "…" --project` |
| 改状态 | `sg status 挂起`（进行中 / 等待 / 挂起 / 已完成 / 已放弃） |
| 自评 | `sg eval --progress 60 --note "…" [--status …] [--project]` |
| 看所有没完结的会话 | `sg list --open`（加 `--here` 只看当前项目） |

用户亲口给出的目标或状态，加 `--by user`；你自己判断写入的，用默认的 `--by ai`。

## 设目标

- 用户给了目标就原样精简成一句话写入，不要自行扩大范围。
- 用户让你「设个目标」但没说内容：根据会话开头的需求起草一句**可验证**的目标（做完能明确判断是否达成），先给用户看，确认后再写。

## 自评流程

1. `sg show` 读目标。没有目标就先按上一节补，不要对着空目标打分。
2. 回顾本会话实际做成的事，只算**已经验证过**的产出（跑通的测试、生成的文件、用户确认过的结论）。写了但没验证的算一半以内。
3. 打分：
   - 100：目标全部达成且已验证，没有遗留。
   - 70–90：主体完成，剩收尾或待用户验收。
   - 30–60：做了一部分，主要难点还在。
   - 0–20：刚开始，或方向变了、之前的工作基本作废。
   - 对话偏离了目标时照实扣分，并在 note 里写明偏到了哪。
4. 写入，note 控制在 80 字内，格式：`已完成：…；剩余：…；偏离：…（没有就省略）`。
   ```
   sg eval --progress 65 --note "已完成：插件后端和日历视图；剩余：自评 skill 联调" 
   ```
5. 状态建议：在等用户/别人回复 → 等待；用户说先放一放 → 挂起；100 且用户认可 → 已完成。**不要未经用户同意把状态改成「已完成」或「已放弃」**，只在回复里建议。
6. 回复用户 2–3 行：分数、依据、下一步。如果偏离了目标，明确问用户是回到原目标还是把目标改掉。

项目自评（`--project`）：先 `sg list --here` 看该项目下各会话的记录，结合项目目标综合评分。
